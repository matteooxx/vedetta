What this file controls

{% if name == 'watchlist' %}

Which employers to watch, on which platforms, with which identifiers. A source is polled only when it carries verified_on. Remove that line and the source stops being polled while staying visible as unwatched — which is the point: an employer you cannot watch should never look like an employer with nothing to say.

{% elif name == 'rules' %}

What counts as a blocker, a warning or a good sign. Three keys matter most:

  • unless — the difference between a language that is required and one that is an asset. Without it a language rule is wrong about half the time.
  • field: title | body | all — what the rule reads. The first real run labelled a "Senior Backend Engineer" as early-career, because the word "graduate" sits in nearly every long description's boilerplate.
  • weight — so that being in a target role cluster outweighs merely being at the right level. Without it an "Associate Renewals Manager" ranked alongside a "Cloud Engineer", which actually happened.

explain is required on every rule, because it is what appears next to the posting in the digest. A rule you cannot explain in one line is a rule you cannot argue with.

{% else %}

Database path, digest time and recipients, ranking weights, and which discovery techniques are enabled. Credentials are never here — they come from the environment file only.

{% endif %}

Severity orders the digest. It never hides anything: a posting that trips every gate in the rule file still appears, lower down, with the reasons shown.
