Sources

An employer can have several routes. Where two exist, both are polled: if one goes quiet while the other still answers, that is a detected fault rather than a closed job.

A source is only polled once a human has confirmed it. While this tool was being built, two completely independent automated methods each returned a different company than the one asked for — one of them a road-paving contractor returned as an asset manager, another a vendor demo board whose only posting was titled "Test Position". Both looked like success. So Sample shows you real titles, and you decide.
